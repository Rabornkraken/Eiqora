# API Endpoint Documentation

The Eiqora API serves as the bridge between the React frontend and the Python analysis engine. It provides endpoints for real-time chat, triggering analysis, and monitoring portfolio performance.

**Base URL:** `http://localhost:8000`

## 1. Chat Interface

Natural language interface for ad-hoc queries.

### `POST /chat`
Process a user message and return a structured response.

**Request:**
```json
{
  "message": "What are the risks of investing in NVDA?",
  "history": []
}
```

**Response:**
```json
{
  "content": "I've started a deep analysis for NVDA...",
  "action": "analyze_stock",
  "data": {"ticker": "NVDA"}
}
```

---

## 2. Dashboard & Performance

Endpoints powering the main trading dashboard.

### `GET /api/dashboard-stats`
Returns high-level metrics for the dashboard header.
*   **Returns:** Total trades, Win rate, Current Equity, Sharpe Ratio.

### `GET /api/equity-history`
Returns historical equity curve for charting.
*   **Returns:** Array of `{date: "2024-01-01", equity: 10500.0}`.
*   *Note:* Combines historical snapshots with live current equity.

### `GET /api/account`
Returns current account summary.
*   **Returns:** Cash balance, Total Equity, Unrealized/Realized P&L.

### `GET /api/watchlist`
Returns the daily candidate list generated by the `CandidateSelector`.
*   **Params:** `date` (optional, YYYY-MM-DD).
*   **Returns:** List of symbols with Technical & Profile scores.

---

## 3. Trading & Positions

Endpoints for portfolio management.

### `GET /api/positions`
Returns currently open positions.
*   **Returns:** Symbol, Entry Price, Current Price, Unrealized P&L, Days Held.
*   *Note:* Triggers a live price refresh on fetch.

### `GET /api/trading-history`
Returns list of closed trades.
*   **Params:** `limit` (default 50).
*   **Returns:** Entry/Exit dates, Prices, Realized P&L.

---

## 4. Analysis & Decisions

Endpoints for reviewing AI decision logs.

### `GET /api/decisions`
List recent trading decisions made by the system.
*   **Params:** `limit`, `offset`, `symbol`, `decision` (GO/NO_GO).
*   **Returns:** Summary list of decisions.

### `GET /api/decisions/{analysis_id}`
Get full details of a specific analysis run.
*   **Returns:** Complete JSON dump of all agent outputs (TopDown, Chart, Red Team, etc.) for forensic review.

### `POST /analysis/start`
Manually trigger an analysis for a specific ticker.
*   **Request:** `{ "ticker": "AAPL" }`
*   **Returns:** `run_id` for polling.

---

## 5. Utilities

### `GET /health`
System health check. Returns `{"status": "healthy"}`.

### `GET /tickers/validate/{ticker}`
Validates if a ticker symbol exists using YFinance.
